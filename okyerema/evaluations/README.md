# Okyerema Evaluations

Test scenarios for validating the Okyerema rhythm engine after installation.

## Evaluations

| File | Capability | Priority |
|------|-----------|----------|
| `01-rhythm-loop.eval.md` | WIEG state machine rhythm loop | Critical |
| `02-health-patrol.eval.md` | Sankofa health patrol patterns | Critical |
| `03-dispatch.eval.md` | Issue dispatch and auto-assignment | Critical |
| `04-verification.eval.md` | Post-action verification checks | High |
| `05-plan-materialization.eval.md` | Plan-to-issues materialization | High |
| `06-integration.eval.md` | Cross-plugin integration | Medium |
| `07-cross-context.eval.md` | Multi-context execution | Medium |

## Running

Follow each `.eval.md` file's setup and test steps in a repository with the Okyerema plugin installed.
