# Okyerema Skills

Copilot skills provided by the Okyerema rhythm engine plugin.

## Skills

| Skill | Purpose |
|-------|---------|
| [rhythm](rhythm/) | Teaches agents the WIEG state machine (Wait → Investigate → Execute → Guard), dispatch patterns, and the rhythm loop for coordinating work |
| [sankofa](sankofa/) | Teaches agents health patrol patterns — detecting orphaned issues, stale work, hierarchy violations, and repo readiness gaps |
